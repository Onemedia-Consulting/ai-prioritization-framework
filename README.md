# AI Prioritization Framework

A Claude Code skill that guides teams through a battle-tested 6-step process for identifying, evaluating, and selecting AI use cases — moving from "AI curiosity" to a first realized production use case with measurable ROI.

## Install

In Claude Code:

```
/plugin marketplace add Onemedia-Consulting/ai-prioritization-framework
/plugin install ai-prioritization-framework
```

That's it. The skill activates automatically when you ask Claude things like:

- "Where should we start with AI?"
- "How do I prioritize AI use cases?"
- "Help me build a business case for AI."
- "We have a list of AI ideas — which should we do first?"

## What the skill does

It produces a prioritized shortlist of AI use cases scored against data readiness and business impact, with a clear recommendation for which **one** use case to start with.

Two operating modes:

- **Full Workshop Facilitation** — walk through all 6 steps from scratch (60–90 min interactive)
- **Assessment & Scoring** — jump in with an existing list of candidates and score them

## The 6 Steps

1. **Use Case Ideation** — generate candidates from pain points, not technology
2. **Brainstorming & Categorization** — organize and dedupe
3. **Document the Status Quo** — baseline how the work is done today
4. **AI Potential Assessment** — traffic-light score across 5 criteria, assign Prio 1/2/3
5. **Impact / Effort Matrix** — plot on a 2x2, find the Quick Wins
6. **Select 1–3 First Use Cases** — define owner, metric, baseline, target, stop/go/scale

Deliverables include a scored assessment matrix, a one-page use case brief, an executive summary, and a 90-day Crawl/Walk/Run roadmap.
